# walle 品牌方向

一句话：`walle —— 一个用 Go 写的轻量 Agent Runtime，会使用工具并修补自己。`

中文：一个用 Go 写的轻量 Agent：会使用工具，也能修补自己。

## 设计母题

简化版 WALL-E 风格小维修机器人：一个会使用工具、能修补自己的小型可靠机器。

## 必须保留的识别比例

- 双筒大眼：这是 WALL-E 机器人形象的核心识别点，也表达 inspect / 观察。
- 分节机械颈：长而可动，使用转轴连接望远镜头与机身。
- 黄色压缩箱：方正厚重，是机器人主体轮廓和视觉中心。
- 大型侧履带：与箱体近似同高，形成推土机式底盘轮廓。
- 侧轨短机械臂：贴在箱体两侧，表达工具执行能力；极小尺寸可并入履带连接线。
- 补丁/更换面板：表达受控的自修改与“缺什么补什么”。

## 字符画原则

字符画以可爱的小型维修机器人为目标：分离望远镜眼占整体近一半，瞳孔保留表情；分节机械颈连接方形压缩箱；大型履带贴在箱体两侧且与箱体近似同高。优先保留 WALL-E 的工程机械轮廓，避免画成细腰人形机器人或圆轮小车。

TUI 主强调色使用品牌橙 `#DFA241` 和琥珀黄 `#F2C14E`；成功、错误等状态色继续承担独立语义。

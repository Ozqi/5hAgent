# 什么是harness

harness是模型无关的。是为LLM服务的。harness和LLM应该轻耦合，只调用LLM client API交互（把LLM 看作一个输入输出都是string的神奇函数即可）；

harness（我们这里具体就是agent runtime）

runtime的上一层是调度。这里的 daemon/supervisor 必须是唯一监管进程，不等于 runtime agent 实例；TUI/CLI 只是 client，连接 supervisor 后 attach 到某个 runtime agent。

过渡实现先使用 `~/.5hAgent/run/supervisor.sock` 固定 socket，清掉旧的 `daemon-*.sock` 多 daemon 语义；最终形态见 `doc/runtime/agent-systemd.md`。

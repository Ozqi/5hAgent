# .doc 入口

一句话：`.doc/` 放内部调研和决策记录；架构图和拓扑事实源放 `.spec/diagrams/`。

## 设计入口

| 文件 | 用途 |
| --- | --- |
| `约定.md` | 仓库内部约定 |
| `runtime-daemon-boundary.md` | runtime / walled 边界 |
| `runtime-interface.md` | runtime 对外接口一图流 |
| `.spec/diagrams/` | 架构图、Mermaid 和拓扑 JSON 事实源 |
| `cordis-plugin-system.md` | Cordis-like 插件系统设计 |
| `codex-oauth-provider.md` | Codex OAuth provider 设计 |
| `codex-oauth-provider.json` | Codex OAuth provider 拓扑事实源 |
| `design-change-log.md` | 未提交 diff 的设计影响记录 |

# .doc 入口

一句话：`.doc/` 放内部设计；能一图流就一图流，参考资料可以长。

## 设计入口

| 文件 | 用途 |
| --- | --- |
| `约定.md` | 仓库内部约定 |
| `runtime-daemon-boundary.md` | runtime / walled 边界 |
| `runtime-interface.md` | runtime 对外接口一图流 |
| `walle-architecture-topology.json` | walle 架构拓扑事实源，供 Mermaid/draw.io 分模块作图 |
| `walle-overall-runtime.mmd` | walle 总览图 Mermaid，来源于拓扑 JSON 的 `view_overall_runtime` |
| `walle-overall-runtime.drawio` | walle 总览图 draw.io 文件，可直接导入 diagrams.net |
| `walle-daemon-control.mmd` | daemon 控制面图，展示 supervisor.sock、ps/attach 和通用 process |
| `walle-agent-turn.mmd` | 单轮 ReAct 时序图，展示输入、上下文、模型、工具和写回 |
| `walle-context-projection.mmd` | 上下文投影图，展示 Full Context、LM Projection 和 prompt cache 分层 |
| `walle-capabilities.mmd` | 能力挂载图，展示固定工具和 planned dynamic capabilities |
| `cordis-plugin-system.md` | Cordis-like 插件系统设计 |
| `codex-oauth-provider.md` | Codex OAuth provider 设计 |
| `codex-oauth-provider.json` | Codex OAuth provider 拓扑事实源 |
| `design-change-log.md` | 未提交 diff 的设计影响记录 |

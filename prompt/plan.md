将下面的任务拆分为 miniTask 列表。

拆分标准：
- 每个 miniTask 是原子的：一次 LLM 调用能完成
- 有明确的输入和可验证的输出
- 粒度：太大拆开，太小合并

任务类型标注：
- exec: 执行操作（写代码、运行命令、修改文件）
- query: 查询信息（读文件、搜索、分析）
- wait: 等待外部事件（编译、测试、网络请求）
- decide: 需要判断或决策（方案选择、评估）

严格按以下格式输出，不要添加解释：

```
T1 [query] <任务描述>
   输入: <前置条件或依赖>
   输出: <可验证的产出>
   依赖: 无

T2 [exec] <任务描述>
   输入: T1 的输出
   输出: <可验证的产出>
   依赖: T1
```

#

比如用户说：“持续主动和我说话，永不停止“

注意这不是一个slash命令，我的harness不会识别，LLM会返回一句话说”好的呀 balabala....“ 然后没有新的工具调用，ReAct循环终止，一次回答就完成了；并没有实现我的需求。

为啥会这样：因为ReAct 循环里，如果你某次回答没有工具调用就会退出。因为源源不断的自我循环（busy poll）会非常消耗token。

如何才能无限拓展LLM的能力边界，且让他能自我感知，自我控制。 持续修正前进。

如果我的harness没提供这个功能，LLM，

Agent应该怎么做，才能做到类似“自修改”

## 确定结论

- 不能让普通 ReAct 循环在“无工具调用”后自动无限继续；这会变成不可控 token busy loop。
- “持续主动推进”应显式建模成任务/进程能力：例如 daemon 监听 `.5hagent/task.md`，或由用户启动 `/run`/headless 任务。
- LLM 自己不能凭一句自然语言承诺获得后台执行权；必须由 harness/runtime 提供事件源、退出条件和预算边界。
- 类似“自修改”的可靠形态不是模型直接改自己，而是：
  - 把待改进点写成 task；
  - 通过工具读取/修改代码或文档；
  - 由 runtime/test/review 验证；
  - 由用户或调度层决定是否继续下一轮。
- 后续如果要支持“持续主动和我说话”，应实现为显式模式，例如 `watch/daemon` 任务或定时事件源，而不是改变普通 TUI 对话的退出条件。

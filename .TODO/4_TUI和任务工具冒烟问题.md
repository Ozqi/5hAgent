# TUI 和任务工具冒烟问题

说明：以下项需要真实 TUI、本地模型或长任务复现后才能关闭。

- `/run` 失败工具行已能表格化显示，但还需要持续观察复杂任务下是否出现新的换行、截断或状态栏错位。
- 当前机器上多次新启动 `5hagent --session ...` 被系统直接 `killed`；需要排查是否为 Ollama/本地模型内存压力、会话加载过大或启动期资源峰值。
- 复杂长任务普通对话模式下，模型连续工具调用约 8 次后会阶段性停下并请求“允许继续推进”，未先写指定报告；需要强化 TUI prompt 或提供“持续执行直到产物存在”的运行模式。
- `write_file` 失败后，模型能二次修正并验证文件存在，但不会主动修正报告内“工具未失败”和错误 task 文件来源等事实问题。
- 空响应 reminder 后，本地模型仍可能在读文件/grep 后空响应终止；需要更强制的继续策略或框架级未完成状态机。
- 最终回复仍可能超过用户要求的“只回复路径和验证结果”；需要真实模型回归验证。
